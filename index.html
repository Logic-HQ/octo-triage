OctoTriage is a lightweight client-side application. It uses GitHub OAuth, fetches only the repository data you select, and keeps local state in your browser—not on a centralized backend.

Minimal access

Requests only the GitHub permissions needed to read and triage your selected repositories.

Local caching

Uses browser storage to improve speed and support offline access to cached board state.

No data resale

No third-party analytics or repository-data marketplace—just a focused maintainer tool.
